# Project instructions

## Keep the README in sync

`README.md` is user-facing documentation. Whenever a change adds, removes, or alters something a user would see or set, update `README.md` in the same change:

- new or removed models / providers (and their thinking/effort behavior)
- new, renamed, or removed CLI flags in `main.py`
- changed defaults in `params.py` (e.g. effort, cache TTL, max tokens)
- new environment variables or provider base URLs

Treat a code change that leaves the README stale as incomplete.
